## Recent updates worth sharing

- **Copilot code review is now GA with a clearer review experience.** Overview
  comments now separate open vs. resolved findings, auto-resolution is
  smarter, and Copilot can auto-generate commit messages when you
  batch-accept suggestions. Good for teaching the day-to-day PR review loop.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-18-copilot-code-review-an-improved-review-experience))
- **Copilot code review can now approve pull requests (public preview).**
  Copilot can add a formal approval assessment to a PR, tying directly into
  lessons on the PR approval and merge workflow.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests))
- **Workflow execution protections in GitHub Actions are now GA.** Repo and
  org admins can allowlist who or what can trigger workflows, including
  per-file targeting — a solid core lesson for teaching Actions security.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available))
- **Refreshed pull requests list page (public preview).** Advanced filters, a
  collapsible sidebar, and a compact view make it easier to scan open PRs —
  worth a mention when covering repository navigation basics.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-10-refreshed-repository-pull-requests-page-in-public-preview))
- **Merges can now be blocked when secrets are exposed in a PR.** A new
  ruleset option prevents merging until secret-scanning alerts are resolved —
  a useful, concrete example for branch protection and merge-safety lessons.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging))
- **GitHub CLI can now attach media to issues, PRs, and comments.** The new
  `gh --attach` flag uploads images or videos straight from the terminal,
  handy for CLI workflow tutorials.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments))
- **New Copilot app beginner tutorials.** "Run several agents at once" and
  "Managing your work" are ready-made walkthroughs for readers new to the
  Copilot app and multi-agent workflows.
  ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-run-several-agents-at-once/),
  [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-managing-your-work/))
