## Recent updates worth knowing (September 2026)

- **Refreshed pull requests page (public preview).** GitHub is rolling out a
  redesigned repository pull requests list that makes it easier to scan,
  filter, and manage open PRs at a glance.
  Source: [GitHub Changelog, Sep 10 2026](https://github.blog/changelog/2026-09-10-refreshed-repository-pull-requests-page-in-public-preview)
- **Control Actions cache access with `cache-mode`.** A new `cache-mode`
  setting lets workflow authors restrict when a job can read or write the
  Actions cache, reducing the risk of stale or poisoned caches in CI.
  Source: [GitHub Changelog, Sep 10 2026](https://github.blog/changelog/2026-09-10-control-github-actions-cache-access-with-cache-mode)
- **Copilot code review can auto-resolve comment threads.** Recent updates to
  Copilot code review add auto-resolution and improved analysis, so fewer
  AI-generated comments need manual triage during PR review.
  Source: [GitHub Changelog, Sep 11 2026](https://github.blog/changelog/2026-09-11-auto-resolution-and-analysis-updates-in-copilot-code-review)
- **VS Code Agents now show up in Copilot usage metrics.** Usage from Copilot
  agent sessions inside VS Code is now included in Copilot usage dashboards,
  giving teams accurate visibility into agent-driven activity.
  Source: [GitHub Changelog, Sep 11 2026](https://github.blog/changelog/2026-09-11-add-vs-code-agents-to-copilot-usage-metrics)
- **Tune cost vs. quality in Copilot's auto model selection.** Copilot's
  "auto" model-selection mode now offers a setting to favor lower cost or
  higher quality, helping teams manage Copilot spend without losing control
  over response quality.
  Source: [GitHub Changelog, Sep 14 2026](https://github.blog/changelog/2026-09-14-configure-cost-and-quality-in-copilot-auto-model-selection)
- **Run several Copilot coding agents at once.** A GitHub Blog tutorial shows
  how to parallelize AI-assisted work by running multiple Copilot agents on
  different tasks at the same time.
  Source: [GitHub Blog, Sep 3 2026](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-run-several-agents-at-once/)
- **Automate Dependabot pull request triage with Copilot.** Another beginner
  tutorial covers using Copilot to automatically triage and respond to
  Dependabot-generated pull requests, cutting down manual review overhead.
  Source: [GitHub Blog, Aug 26 2026](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-automate-dependabot-pull-request-triage/)
