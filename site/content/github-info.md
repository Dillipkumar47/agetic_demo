# GitHub Info

## Mona's editorial angle

- docs.github.com

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.

- Recent GitHub Blog and Changelog stories worth watching.

## Recent updates worth watching

### GitHub Copilot

- **Copilot code review: more ways to request and configure reviews** — Copilot
  code review now supports more triggers and settings, making it easier to
  standardize automated PR review policy across a repo or org.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-23-copilot-code-review-more-ways-to-request-and-configure-reviews))
- **Local sandboxing in the GitHub Copilot app** — Copilot agent edits and
  commands can now run in a local sandbox, giving developers safer autonomy
  when letting Copilot make changes on their behalf.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-23-local-sandboxing-in-the-github-copilot-app))
- **Claude Opus 5.5 now available in GitHub Copilot** — A new selectable model
  for Copilot Chat and agent tasks, giving developers another option when
  choosing the right model for a job.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-22-claude-opus-5-5-is-now-available-in-github-copilot))

### GitHub Actions

- **Node 20 is no longer available in GitHub Actions** — Workflows and custom
  actions still pinned to `node20` need to migrate now, since Actions runners
  no longer support it.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-23-node-20-is-no-longer-available-in-github-actions))

### Collaboration

- **Refreshed repository pull requests page is generally available** — A
  redesigned PR list and tab makes it easier to scan, filter, and manage pull
  requests at the repository level — core reading for anyone learning the PR
  workflow.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-21-refreshed-repository-pull-requests-page-generally-available))
- **Personal saved views for repository issues, plus "Relates to" issue
  links, are generally available** — Saved views and richer issue linking make
  it easier for teams to organize and track collaborative work.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-25-personal-saved-views-for-repository-issues-and-more))
- **Highlights from Git 2.56** — A roundup of what's new in the latest Git
  release, useful background for developers reinforcing branching and merging
  fundamentals.
  ([GitHub Blog](https://github.blog/open-source/git/highlights-from-git-2-56/))
