## Recent updates worth watching (September 2026)

### GitHub Copilot

- **Copilot code review can now approve pull requests.** When enabled by admins, Copilot can assess a ready PR and approve it directly, speeding up low-risk merges. ([GitHub Changelog, Sept 1, 2026](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests))
- **Copilot code review has an improved review experience.** Reviewers get clearer visibility into how a review evolves, smarter auto-resolution of addressed suggestions, and auto-generated commit messages. ([GitHub Changelog, Sept 18, 2026](https://github.blog/changelog/2026-09-18-copilot-code-review-an-improved-review-experience))
- **Project HydraFusion (research preview).** A multi-model orchestration approach inside Copilot aims to deliver frontier-level coding quality at lower cost — worth watching as it may change how Copilot picks models for a task. ([GitHub Blog, Sept 4, 2026](https://github.blog/ai-and-ml/github-copilot/project-hydrafusion-frontier-quality-via-multi-model-orchestration/))

### GitHub Actions

- **Workflow execution protections are now generally available.** Organizations can restrict which actors and events are allowed to trigger workflows, hardening CI pipelines against supply-chain attacks. ([GitHub Changelog, Sept 17, 2026](https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available))
- **Actions platform updates (early September 2026).** Adds a runner-deprecation API, a new `vulnerability-alerts` token permission, and additional context properties for reusable workflow jobs. ([GitHub Changelog, Sept 3, 2026](https://github.blog/changelog/2026-09-03-github-actions-early-september-2026-updates))

### Pull requests, branches, and collaboration

- **Block pull requests with exposed secrets from merging.** Repository rulesets can now prevent a merge when a PR triggers a secret-scanning alert, stopping leaked credentials before they land. ([GitHub Changelog, Sept 9, 2026](https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging))
- **Refreshed repository pull requests page (public preview).** A redesigned PR list adds better filtering, search, and a compact view, making it easier to triage large volumes of open PRs. ([GitHub Changelog, Sept 10, 2026](https://github.blog/changelog/2026-09-10-refreshed-repository-pull-requests-page-in-public-preview))
- **GitHub CLI adds media support for issues, PRs, and comments.** The `gh` CLI now supports an `--attach` option to upload and inline images or videos without switching to the web UI. ([GitHub Changelog, Sept 1, 2026](https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments))
