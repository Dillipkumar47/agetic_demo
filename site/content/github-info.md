## Recent updates worth watching

- **Refreshed repository pull requests page is now GA.** The redesigned
  per-repository PR list makes it easier to find and act on pull requests
  without leaving the repo view — a direct upgrade to everyday collaboration
  workflows.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-21-refreshed-repository-pull-requests-page-generally-available))
- **More AI models available in Copilot.** Claude Opus 4.5, GPT-5.1 variants,
  and Grok 4.1 have all rolled out as selectable models for agentic coding and
  long-running tasks, giving developers more choice for different coding and
  reasoning workloads.
  ([GitHub Changelog: Claude Opus 4.5](https://github.blog/changelog/2026-09-22-claude-opus-4-5-is-now-available-in-github-copilot),
  [GPT-5.1 variants](https://github.blog/changelog/2026-09-22-openais-gpt-5-1-is-now-available),
  [Grok 4.1](https://github.blog/changelog/2026-09-21-grok-4-1-is-now-available-in-github-copilot))
- **Copilot for JetBrains gains agentic controls.** The v1.18.0 update adds
  AI-assisted tool approvals, finer control over agent conversations, and
  shared org-wide skills/instructions — useful for teams standardizing Copilot
  usage across IDEs.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-22-new-features-and-improvements-in-copilot-for-jetbrains))
- **Faster C++ code intelligence in Copilot CLI.** Whole-codebase indexing now
  supports even multi-million-line C++ repos, improving accuracy and speed for
  large legacy projects.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-22-faster-c-code-intelligence-with-whole-codebase-indexing))
- **Security improvements for SSH.** GitHub is removing RSA SSH signature
  support, adding a new signing algorithm, and requiring larger RSA key sizes —
  worth reviewing if your workflow relies on SSH authentication.
  ([GitHub Changelog](https://github.blog/changelog/2026-09-22-security-improvements-for-ssh))
- **Actions beyond CI/CD.** A blog walkthrough shows using GitHub Actions,
  Issues, and Copilot together to automate non-engineering workflows (event
  operations), illustrating how Actions can extend past pure build/test/deploy
  pipelines.
  ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/marketing-ops-as-code-automating-events-from-planning-to-follow-up-on-github/))
