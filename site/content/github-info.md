## Recent updates worth watching

- **Refreshed repository pull requests page is now GA.** The redesigned per-repo
  "Pull requests" tab makes it easier to filter and find PRs — worth a look if your
  team relies on the PR list to triage work.
  Source: [GitHub Changelog, Sep 21, 2026](https://github.blog/changelog/2026-09-21-refreshed-repository-pull-requests-page-generally-available)

- **Grok 4.7 is now available in GitHub Copilot.** xAI's Grok 4.7 joins the list of
  selectable Copilot models, tuned for agentic, multistep coding tasks — try it when
  a task needs multiple coordinated steps.
  Source: [GitHub Changelog, Sep 21, 2026](https://github.blog/changelog/2026-09-21-grok-4-7-is-now-available-in-github-copilot)

- **Copilot code review has an improved review experience.** Expect clearer review
  timelines, smarter auto-resolution of stale suggestions, and auto-generated commit
  messages when you accept Copilot's fixes — less manual cleanup during review.
  Source: [GitHub Changelog, Sep 18, 2026](https://github.blog/changelog/2026-09-18-copilot-code-review-an-improved-review-experience)

- **Code coverage ruleset condition can now be managed via the REST API.** The
  "Restrict code coverage" repository ruleset condition is GA over the REST API, so
  teams can automate coverage-gating policy instead of configuring it only in the UI.
  Source: [GitHub Changelog, Sep 18, 2026](https://github.blog/changelog/2026-09-18-manage-the-code-coverage-ruleset-condition-with-the-rest-api)

- **GitHub is using Copilot to migrate its own Copilot runtime to Rust.** An
  engineering deep-dive on how GitHub's team used Copilot to help migrate a
  production service — a useful real-world example of Copilot on a large,
  incremental refactor.
  Source: [GitHub Blog, Sep 17, 2026](https://github.blog/ai-and-ml/generative-ai/migrating-the-github-copilot-runtime-to-rust-using-copilot/)
